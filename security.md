## Intended Users
This repo is intended for me, other students, and my professor for completing and viewing assignments for this class

## Assessment of Risk of Security Threats
The security risk is low because the repo only has class assignments. It doesn't contain any sensitive personal info, passwords, or real-life data. If someone accessed this repo the only risk would be unauthorized changes and copying my completed code.

## Steps Taken to Secure Repo
To secure the repo, I will make sure that I am only using it for its intended purposes and not storing any sensitive information like passwords, API keys, or sensitive data. There is a CODEOWNERS which just lets us know who is responsible for reviewing changes to the repo. Other rulesets aren't really necessary because this repo is only used for class assignments so it doesn't have any sensitive data we need to protect.
